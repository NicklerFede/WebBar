# 🍔 BURGER & BAR - Sistema de Pedidos & Delivery

Sistema web de gestión gastronómica diseñado para la administración de menús, comandas en tiempo real y control de caja, con sincronización en la nube mediante Firebase Firestore.

## 🚀 Características Principales
- **Menú Público Online:** Visualización interactiva de productos, selección de modalidad (Delivery o Take Away) y armado de pedidos personalizados con ingredientes a gusto para enviar directamente por WhatsApp.
- **Panel de Administración:** Control total protegido por contraseña, gestión de productos (pausar, activar, editar), impresión de comandas y métricas financieras en tiempo real.
- **Sincronización Cloud:** Conectado a Firebase Firestore para mantener los datos sincronizados al instante en múltiples dispositivos.

## 🛠️ Tecnologías Utilizadas
- HTML5 / Tailwind CSS (Diseño responsive y moderno)
- JavaScript (Módulos ES6)
- Firebase Firestore & SDK v10 (Base de datos en tiempo real)
